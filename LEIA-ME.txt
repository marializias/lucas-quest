LUCAS QUEST — versão unificada mobile v1.3

Correções desta versão:
- botão INTERAGIR executa o mesmo comando da tecla E, inclusive dentro dos puzzles;
- coordenadas finais de portas e interações incorporadas ao jogo;
- novo identificador de armazenamento para ignorar colisões antigas salvas no navegador;
- no celular, colisões retangulares antigas são desativadas para impedir bloqueios incompatíveis com os backgrounds;
- arquivos CSS e JS usam versão no endereço para evitar cache antigo no GitHub Pages.

Para atualizar o GitHub Pages, envie todos os arquivos desta pasta substituindo os existentes.
Depois, abra o site em uma aba anônima ou recarregue a página.
